Frozen selection (reference definitions):
1. K* mass window: 0.796 < Kstr_M < 0.996.
2. Charmonium vetoes on m_ll — electron channel: not in (2.846, 3.176) and not in (3.439, 3.719), plus the photon-conversion cut m_ll > 0.14; muon channel: not in (2.946, 3.176) and not in (3.539, 3.719).
3. PID — leptons: both lepton ID > 0.9 (electronID for e, muonID for mu) and both lepton momenta p > 0.4 GeV (e) / 0.8 GeV (mu), using the branches <lep>1_<B>_<ID>, <lep>2_<B>_<ID>, <lep>1_<B>_p, <lep>2_<B>_p. Pion: pi_Kstr_pionID / (pi_Kstr_pionID + pi_Kstr_kaonID) > 0.6, applied unless Kstr_decayModeID == 1 (pi0 mode has no charged pion). In the neutral channel both apply.
4. Best candidate: among the candidates passing cuts 1-3, keep per event the one with the smallest abs(deltaE) (tool argument best_by="abs(deltaE)"). Do NOT use the stored B_rank branch, which was computed before these cuts.
5. Signal box: 5.27 < Mbc < 5.29 and abs(deltaE) < 0.05, applied to the best candidate (tool argument post_selection).
